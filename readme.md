# บันทึกการฝึกเรียนรู้การแก้ปัญหาในเว็บ leetcode

## เป้าหมาย

full-stack / backend dev ที่มีคุณภาพไม่ใช่แค่เขียนโค้ดได้แต่เป็นเลือกวิธีการแก้ปัญหาเป็นและมีประสิทธ์ภาพ

แล้วยังฝึกเพื่อไปจับผิด AI agents ที่เขียนโค้ดแทนคน / และเผื่อโทเคนหมดก็สามารถทำงานต่อจาก AI ได้และตั้งใจใช้เวลาเขียนโค้ดและเรียนรู้ประมาณ 1-2 ชั่วโมงต่อวัน
