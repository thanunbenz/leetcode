# บันทึกการฝึกเรียนรู้การแก้ปัญหาในเว็บ leetcode

เป้าหมายก็คือ full-stack / backend dev ที่มีคุณภาพไม่ใช่แค่เขียนโค้ดได้แต่เป็นเลือกวิธีการแก้ปัญหาเป็นและมีประสิทธ์ภาพ

แล้วยังฝึกเพื่อไปจับผิด AI agents ที่เขียนโค้ดแทนคน / และเผื่อโทเคนหมดก็สามารถทำงานต่อจาก AI ได้และตั้งใจใช้เวลาเขียนโค้ดและเรียนรู้ประมาณ 1-2 ชั่วโมงต่อวัน

โดยโฟนเดอร์นี้แบ่งไปตาม level ของโจทย์บน leetcode ประกอบด้วย

`easy` | `mid` | `hard`

โดยภาษาหลังในการทำคือ JS ซึ้งเป็นภาษาที่ถนัดที่สุดตอนนี้

วันนี้เริ่มเขียนไออารี่นี้อย่างจริงจัง 16/11/2026

## 16/11/2026

- ทำไปทั้งหมดรวมวันที่ไม่ได้บันทึก 4 ข้อ
- วันนี้ได้ทำทั้งหมด 2 ข้อ ในโหมด Easy
  1. isPalindrome
  2. longestCommonPrefix

### สิ่งที่ทำวันนี้

- เกิดการเรียนรู้และปัดฝุ่นความรู้เก่าและเพิ่มการเขียนแบบใหม่ๆเช่น function build-in ที่มากับ JS เวอร์ชั่นใหม่ๆ ES-6 เป็นต้นมา
- แต่วันนี้ตั้งเป้าหมายว่าต้องเรียนรู้ BigO / Data Structures ให้ดีกว่านี้เพื่อให้โค้ดที่ส่งไปบน leetcode

### ข้อเสียของวันนี้

- ยังอ่านภาษาอังกฤษไม่ค่อยแตก
- ยังเจอบัคแล้วยังหงุดหงิดต้องวิ่งหา AI ช่วยอธิบาย
- ยังต้องมี AI ค่อยช่วยแก้อยู่

### เป้าหมายของวันพรุ้งนี้หรือวันต่อไป

- อ่านภาษาอังกฤษให้แตก เลิกใช้ แปลภาษา
- เข้าใจโจทย์มากขึ้น
- เข้าใจการแก้ปัญหาที่ดีกว่านี้
- เรียนรู้การใช้พวก build-in function ต่างๆที่มีมาแล้ว
- ทำข้อ isValid ต่อให้จบ
